ERP Architecture

Django monolith — Purchase / Sales / Inventory ERP, single-process, SQLite-backed, no cloud services

Security & Access Control

  • • Custom RBAC: Function (permission unit) → Role (M2M to Function & User)
  • • Sidebar built per-request from JSON, filtered to only functions the user's role(s) grant
  • • backend app gated by UserPassesTestMixin (is_staff)
  • • Auth via django.contrib.auth: login/logout/register/password-change
  • • Dev config: password validators disabled, DEBUG=True, insecure SECRET_KEY

Tech Stack

  • • Python 3.12+, Django 6.0+
  • • AdminLTE 4 + Bootstrap 5 + Popper + OverlayScrollbars, all via jsDelivr CDN
  • • Vanilla ES6 JavaScript — no bundler/framework
  • • openpyxl for Excel import/export (sales module)
  • • No cloud services — single local process, no queue/cache/object storage

Data & App Boundaries

  • • Single SQLite file (db.sqlite3), 7 apps each with own migrations
  • • inventory is the shared base domain
  • • purchase & sales call inventory.services one-directionally — inventory has no reverse dependency
  • • URL split: /front/* (operational), /back/* (admin), /accounts/* (auth), /django-admin/* (built-in)
