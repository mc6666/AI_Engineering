  Searched for 2 patterns, read 5 files, ran 1 shell command (ctrl+o to expand)

● The issue is very likely caused by my earlier fix. I set the
  AdminLTE/Bootstrap/OverlayScrollbars scripts to strategy="beforeInteractive",
  which makes them execute before React hydrates. AdminLTE's layout script
  mutates the DOM on load (e.g. sidebar/theme classes on <body>), so by the time
  React hydrates, the live DOM no longer matches what was server-rendered —
  that's exactly what triggers "Hydration failed because the server rendered
  HTML didn't match the client."

  These scripts aren't critical-path (no bot-detection/consent-manager-style
  requirement to run pre-hydration), so they should use afterInteractive
  instead, which runs after hydration completes and avoids the race.
