# 書名：AI Engineering 實戰, 重塑個人技能、改造開發團隊與工作流程

## 本書主要分為兩篇，AI Coding與AI Agent開發
### 第一篇介紹AI Coding，特點如下：
1.	AI Coding工具的使用：同時涵蓋Claude Code及OpenAI Codex，並比較其差異。
2.	氛圍編碼(Vibe Coding)與『規格驅動開發』(SDD)實作：Vibe Coding可以快速產生程式碼，SDD讓我們產生有品質的程式碼。
3.	實作案例：
  - 多平台：含桌面、網頁、手機及Client/Server程式。
  - 工具：計算機(Calculator)、筆記本(Notebook)、影像處理與特效、繪圖設計師(Matplotlib Designer)及Markdown規格預覽器…。
  - 遊戲：打磚塊(Breakout)、配對記憶力測驗、大富翁遊戲…。
  - 應用程式：機器學習、人臉辨識、進銷存系統、企業內部簽核系統、YouTuber美食推薦、即時通訊的多國客服系統、登入機制(Authentication)/Google OAuth整合…。
4.	軟體工程與軟體開發生命週期的蛻變：探討方法論、工具與新思維。
5.	AI Coding對個人核心技能與組織變革的影響。

### 第二篇介紹AI Agent的開發，特點如下：
1.	OpenAI API的使用說明。
2.	工具函數呼叫(Tool Calling)：建立LLM與應用程式的雙向溝通管道。
3.	AI Agent：開發自主運作的Agent，包括多智能體(Multi- Agent)、護欄(Guardrail)、人類參與流程(Human-in-the-loop, HITL)…等。
4.	MCP：提供通訊協定，讓LLM能透過更有彈性的方式連結本機或遠端的AI Agent及資源。
5.	RAG：提供企業或網際網路的知識庫檢索，整合Agent，開發出更有智慧的Agent。
6.	駕馭工程(Harness Engineering)：定義各種機制，讓Agent能在被人類穩定駕馭的系統環境中運行。
7.	LangChain、DeepAgents函數庫應用與實作。

### 閱讀重點
- 第一章介紹大型語言模型(LLM)的發展趨勢及相關基本知識、程式開發的進化及軟體工程方法論的發展趨勢與現況。
- 第二章介紹AI Coding入門與簡單實作。
- 第三章介紹Claude Code與OpenAI Codex安裝與使用，包括常用指令、技能(Skill)檔案系統規劃。並實作計算機(Calculator)、打磚塊(Breakout)、企業內部簽核系統、YouTuber美食推薦…。
- 第四章介紹各種規格驅動開發(Spec-Driven Development, SDD)方法論，以Claude Code與OpenAI Codex為基礎，以規格優先(Spec-first)精神開發應用系統。
- 第五章介紹Agent Skill撰寫技巧，包括需求分析、與Coding Agent的腦力激盪、EARS撰寫技巧、圖表(Diagram)支援、進銷存系統開發實戰及詞元經濟學/省錢秘訣。
- 第六章介紹Git/GitHub版本控管基本概念及操作，以完整範例說明如何在專案中使用Git/GitHub，確保與Coding Agent的協作過程中，能管理好各個版本的程式碼。
- 第七章介紹OpenAI API，作為開發AI Agent的基礎，還介紹即時對話API，並與WebRTC/WebSocket整合，實作多媒體/多語系的對話系統(ChatBot)核心架構。
- 第八章介紹AI Agent開發，從基礎的Tool Calling，再依序介紹Agent、MCP，到Harness Engineering，並介紹OpenAI Agents SDK、LangChain及Deep Agents函數庫，實作加值營業稅計算與發票列印、Multi-agent、護欄(Guardrail)、Human in the loop及長短期記憶等Harness Engineering的機制。
- 第九章介紹模型上下文協定(MCP)的概念與實作，透過MCP通訊協定，讓應用程式更容易連結本機或遠端的工具及AI Agent，很方便的存取外部資源，包括資料庫、開發環境(Git/GitHub)及網路服務(Email、雲端硬碟、行事曆…)，甚至本機的資料夾、週邊設備…等。並利用MCP Python SDK及FastMCP實作本地/遠端MCP Server/Client，還包括Anthropic Desktop佈署、FastAPI整合。
- 第十章介紹如何以檢索增強生成(RAG)建構知識庫，實作完整的RAG工作流程，包括詞嵌入(Embedding)、分塊(Chunking)、向量資料庫(Vector Database)、重新排序(Reranking)及語意搜尋(Semantic search)，並針對RAG有7個可能的失敗點提出各種RAG變形(Variants)作法，以提高RAG的準確率。
- 第十一章介紹工程師應該如何重塑本職學能，IT部門應該如何進行組織變革，以因應新的軟體工程(SDD)及軟體開發生命週期(AI-DLC)。另外加個彩蛋，介紹Jev，它是一個System One決策模型，提供LLM以外的另類創新。
