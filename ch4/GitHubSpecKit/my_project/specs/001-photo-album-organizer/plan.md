# Implementation Plan: Photo Album Organizer

**Branch**: `001-photo-album-organizer` | **Date**: 2026-06-14 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/001-photo-album-organizer/spec.md`

## Summary

A single-user local photo organizer built with NiceGUI. The application runs a local web server
and opens in the default browser. Users import photos from their local filesystem; the app reads
EXIF metadata to auto-group photos into date-based albums. Photo metadata and album ordering are
stored in a local SQLite database. Image files are never moved or copied — only their paths are
recorded. Thumbnails are generated by Pillow on import and cached in an app data directory.
Albums are displayed as draggable cards on the main page using SortableJS for reorder persistence.

## Technical Context

**Language/Version**: Python 3.11+

**Primary Dependencies**:
- NiceGUI ≥1.4 (local web UI framework, Quasar/Vue.js under the hood)
- Pillow ≥10.0 (EXIF metadata extraction + thumbnail generation)
- aiosqlite ≥0.19 (async SQLite; matches NiceGUI's async event loop)

**Storage**: SQLite — local file (`data/photo_organizer.db`) for album and photo metadata.
Photo image files remain at their original filesystem paths; generated thumbnails are cached at
`thumbnails/{photo_id}.jpg` relative to the project root.

**Testing**: pytest ≥7.0 with pytest-asyncio for async service and database tests.

**Target Platform**: Local desktop (Windows/macOS/Linux). NiceGUI opens the app in the default
browser via `localhost`. Fully offline; no network required; single-user; no authentication.

**Project Type**: Local desktop web application (NiceGUI single-project)

**Performance Goals**:
- Batch import of 20 photos grouped into correct date albums within 30 seconds (SC-001)
- Main page with 50 album cards loads in under 3 seconds (SC-002)
- Drag-and-drop visual feedback within 300 ms; order saved within 1 second (SC-003)
- Album tile grid of 100 photos renders within 3 seconds (SC-004)

**Constraints**: Images never moved or copied from original location. App works entirely offline.
Single-user, no auth. Thumbnails pre-generated at import time to meet tile-render performance
targets.

**Scale/Scope**: Single user; designed for hundreds of albums and thousands of photos.

**Structure Decision**: Single-project layout. NiceGUI merges UI and backend into one Python
process, making a frontend/backend split unnecessary. UI concerns are isolated in `src/ui/`;
business logic in `src/services/`; database entities in `src/models/`.
